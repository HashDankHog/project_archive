# Project Archive
Archive of the various mini programming projects I've done over the past ~7 years or so.

Since the vast majority of the coding I have ever done has manifest itself in mini projects not large enough to deserve their own repos, I decided to put it all in one repo.
I am hoping that someone younger than me will stumble across this and see three things:

1) Coding projects do not have to be ambitious. I learned most of my coding skills through the small stuff
2) Learning this stuff took me years.
3) Coding can be a way to express yourself.

## Organization
Everything is split into folders. At the top layer, I have split my projects into categories(games, math, electronics,etc) and then from their I have a folder for every project.
Most projects are only one file, but every project is accompanied by a read-me with instructions on how to run the code and a screenshot when applicable.
